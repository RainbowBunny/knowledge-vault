## Propositions

**Definition**: A *proposition* is a statement that is either true or false.

## Principle of Mathematical Induction

> [!principle] Proof by Mathematical Induction
> Let $A(n)$ be a statement depending on an integer $n$.
> To prove that $A(n)$ holds for all $n \ge n_1$, it suffices to show:
>
> 1. (**Base case**) $A(n_1)$ is true.
> 2. (**Inductive step**) For an arbitrary but fixed integer $k \ge n_1$,
>    assume that $A(k)$ is true and prove that $A(k+1)$ is also true.

> [!principle] Principle of Mathematical Induction
> Let $S$ be a set of positive integers which has the following two properties:
> 1. The number $1$ is in the set $S$.
> 2. If an integer $k$ is in $S$, then so is $k + 1$.
> 
> Then every positive integer is in the set $S$.

 > [!principle] Well-Ordering Principle
 > Every nonempty set of positive integers contains a smallest number.
