The origin note for **center**: stated once, for a single binary operation. Each structure keeps its own center, which says `Extends:: [[Center]]` (a note) or opens with `Specializes [[Center]]` (a section), and carries only what that structure adds.

## Scope

A [[Magma]] $(M, \star)$ — only [[Commutativity]], checked element by element, is involved.
