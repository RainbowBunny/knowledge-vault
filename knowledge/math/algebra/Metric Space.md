## Definition

> [!definition] Norm Function
> Let a set $\mathcal X$ be an additive group. Define the norm function $\mathcal N: \mathcal X \rightarrow \mathbb R$ on $\mathcal X$. This function should satisfy the following axioms:
> 1. (Non-negativity) $\mathcal N(x) \geq 0$;
> 2. (Positive definite or point-separating)$\mathcal N(x) = 0 \Longleftrightarrow x = 0$;
> 3. (Triangle inequality) $\mathcal N(x + y) \leq \mathcal N(x) + \mathcal N(y)$.

> [!definition] Pairwise Distance
> The distance between elements $x, y \in \mathcal X$ is
> $$d(x, y) = \mathcal N(x - y)$$

> [!definition] Metric Space
> An additive group $\mathcal X$ equipped with the norm function $\mathcal N: \mathcal X \leftarrow \mathbb R$ is called a metric space.
