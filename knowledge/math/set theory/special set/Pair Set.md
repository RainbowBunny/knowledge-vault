## Definition

> [!definition] Pair Set
> Specializes:: [[Set]].
> Requires:: [[Axiom of Set Theory]].
> 
> ---
> For any sets $u$ and $v$, the **pair set** $\{u, v\}$ is the set whose only members are $u$ and $v$.
