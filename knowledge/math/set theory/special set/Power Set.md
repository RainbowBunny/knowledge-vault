## Definition

> [!definition] Power Set
> Specializes:: [[Set]].
> Requires:: [[Axiom of Set Theory]].
> 
> ---
> For any set $a$, the **power set** $\mathcal{P}(a)$ is the set whose member are exactly the subsets of $a$.

## Property

> [!theorem]
> Requires:: [[Union Set]], [[Intersection Set]].
> 
> ---
> - $\forall A, B: \mathcal{P}(A) \cap \mathcal{P}(B) = \mathcal{P}(A \cap B)$.
> - $\forall A, B: \mathcal{P}(A) \cup \mathcal{P}(B) \subseteq \mathcal{P}(A \cup B)$.
> - $a \in B \implies \mathcal{P}(a) \in \mathcal{P} \mathcal{P}(\bigcup B)$.
