## Definition

> [!definition] Symmetric Difference
> Define the symmetric difference $A + B$.
> $A + B = (A - B) \cup (B - A)$.

## Property

> [!proposition] Associativity of Symmetric Difference 
> $+$ satisfies [[Associativity]]:
> $A + (B + C) = (A + B) + C$.

> [!proposition] Distributivity of Symmetric Difference and Intersection
> Requires:: [[Intersection Set]].
> 
> ---
> $+$ and $\cap$ satisfies Left [[Distributivity]]:
> $A \cap (B + C) = (A \cap B) + (A \cap C)$.
