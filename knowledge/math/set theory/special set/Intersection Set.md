## Definition

> [!definition] Intersection Set
> Specializes:: [[Set]].
> Requires:: [[Axiom of Set Theory]].
> 
> ---
> $\forall a \; \forall c \; \exists B \; \forall x (x \in B \iff x \in c \land x \in a)$.
> This set $B$ is defined to be the **intersection** $c \cap a$ of $c$ and $a$.

> [!theorem] Arbitrary Intersection
> For any nonempty set $A$, there exists a unique set $B = \bigcap A$ such that
> $$\forall x (x \in B \iff \forall a \in A : x \in a)$$
