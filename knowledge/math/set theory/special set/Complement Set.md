## Definition

> [!definition] (Relative) Complement Set
> Specializes:: [[Set]].
> Requires:: [[Axiom of Set Theory]].
> 
> ---
> $\forall A \; \forall B \; \exists S \; \forall t [t \in S \iff t \in A \land t \notin B]$.
> This set $S$ is the **relative complement** of $B$ in $A$, denoted $A \backslash B$ (or $A - B$).

> [!definition] Complement Set
> Usually, we have a universal set $S$, and denote the complement of a set $A$ as:
> $$S - A = -A.$$
