# Data Structures MOC

> [!definition] Data Structures
> A **data structure** is a way to store and organize data in order to facilitate access and modifications. No single data structure works well for all purposes, so it is important to know the strengths and limitations of several of them.

- [[Heap]] — binary heap, $d$-ary heap, mergeable heaps, Young tableaus
- [[Priority Queues]] — abstract operations + heap implementation

## Trees

- [[Binary Search Tree]] — BST property, traversals, querying, insertion/deletion
- [[Red-Black Trees]] — properties, rotations, insertion/deletion fixup
- [[B-Trees]] — disk-friendly multiway trees, split-child, insert

## Hashing

- [[Hash Tables]] — direct-address, chained, open addressing (linear/quadratic/double), perfect hashing

## Linear Structures

- [[Stacks and Queues]] — stack, queue, dequeue
- [[Linked Lists]] — doubly linked, singly linked

## Sets

- [[Disjoint Sets]] — linked-list, disjoint-set forests (union by rank, path compression), connected components
