## Definition

> [!definition] Machine Encoding
> Requires:: [[Simple Encoding]].
> Every string in $\{0, 1\}^*$ represents some Turing machine $M$ and denoted $\langle M \rangle$ as the binary description of $M$.

## Property

> [!proposition]
> Every machine has infinitely many representations (padding).
