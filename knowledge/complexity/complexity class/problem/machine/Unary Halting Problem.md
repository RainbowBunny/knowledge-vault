## Definition

> [!definition] Unary Halting Problem
> Reference Name: $\mathsf{UHALT}$.
> 
> ---
> The set of unary representation of $n$ such that $n$'s binary expansion encodes a pair $\langle M, x \rangle$ such that $M$ halts on input $x$.
