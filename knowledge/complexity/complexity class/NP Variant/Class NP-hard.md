## Definition

> [!definition] Class NP-hard
> Requires:: [[Polynomial-time Karp Reducibility]]
> 
> ---
> A [[Language]] $\mathcal{L} \in \mathsf{NP}\mbox{-}\mathsf{hard}$ if:
> $$\forall \mathcal{L'} \in \mathsf{NP}: \mathcal{L} \leq_p \mathcal{L}'.$$
