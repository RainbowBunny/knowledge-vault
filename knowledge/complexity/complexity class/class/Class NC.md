## Definition

> [!definition] Class NC
> For every $d$, a [[Language]] $\mathcal{L}$ is in $\mathsf{NC}^d$ if $\mathcal{L}$ can be decided by a [[Circuit Family]] $\{C_n\}$ where $C_n$ has $\mathsf{poly}(n)$ size and depth $O(\log^d n)$.
> $\mathsf{NC} = \cup_{i \geq 1} \mathsf{NC}^i$.
