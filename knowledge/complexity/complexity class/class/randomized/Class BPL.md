## Definition

> [!definition] Class Bounded Polynomial Logarithm space
> A [[Language]] $\mathcal{L}$ is in $\mathsf{BPL}$ if there is an $O(\log n)$-space [[Probabilistic Turing Machine]] $M$ such that $\Pr[M(x) = \mathcal{L}(x)] \geq \frac{2}{3}$.
