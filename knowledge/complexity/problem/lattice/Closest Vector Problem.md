## Problem

> [!definition] The Closest Vector Problem ($\text{CVP}$)
> Given a vector $\textbf{w} \in \mathbb R^m$ that is not in $L$, find a vector $\textbf{v} \in L$ that is closest to $\textbf{w}$, i.e., find a vector $\textbf{v} \in L$ that minimizes the Euclidean norm $||\textbf{w} - \textbf{v}||$.

> [!definition] Approximate Closest Vector Problem ($\text{apprCVP}$)
> This is the same as $\text{apprSVP}$ but now we are looking for a vector that is an approximate solution to $\text{CVP}$, instead of an approximate solution to $\text{SVP}$.
