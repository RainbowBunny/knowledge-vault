## Spacing command

| Latex Code   | Description                                      |
| ------------ | ------------------------------------------------ |
| $a \quad a$  | Space equal to the current font size (= `18` mu) |
| $a \, a$     | `3` mu                                           |
| $a \: a$     | `4` mu                                           |
| $a \; a$     | `5` mu                                           |
| $a \! a$     | `-3` mu                                          |
| $a\ a$       | Space in text                                    |
| $a \qquad a$ | `36` mu                                          |
