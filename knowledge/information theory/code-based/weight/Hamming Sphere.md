## Definition

> [!definition] Hamming Sphere
> Hamming Sphere, denoted $\mathcal{S}_w^n(\mathbb{F}_q)$ is the set of codewords $m$ of length $n$ with alphabet $\mathbb{F}_q$ that has [[Hamming Weight]] $\mathsf{wt}_\mathsf{H}(m) = w$. 
> Thus, we have 
> $$|\mathcal{S}^n_w(\mathbb{F}_q)| = \binom{n}{w} (q - 1)^w$$
