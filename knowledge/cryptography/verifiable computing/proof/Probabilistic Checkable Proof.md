## Syntax

> [!definition] Probabilistic Checkable Proof
> A probabilistic checkable proof system (PCP) for a language $\mathcal L \subseteq \{0, 1\}^*$ consists of a probabilistic polynomial time verifier $\mathcal V$ who is given access to an input $x$, and oracle access to a proof string $\pi \in \Sigma^\ell$.
