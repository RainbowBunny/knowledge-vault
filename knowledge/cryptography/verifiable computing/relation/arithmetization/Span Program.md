## Definition

> [!definition] Span Program
> A span program (SP) over a [[Field]] $\mathbb{F}$ consists of:
> - A nonzero target vector $\mathbf{t}$ over $\mathbb{F}$.
> - A set $\mathcal{V} = \{\mathbf{v}_1, \dots, \mathbf{v}_m\}$ of vectors.
> - A partition of the indices $\mathcal{I} = \{1, \dots, m\} = \mathcal{I}_\mathrm{labeled} \cup \mathcal{I}_\mathrm{free}$.
> - A further partition $\mathcal{I}_\mathrm{labeled} = \cup_{i \in [n], j \in \{0, 1\}} \mathcal{I}_{i j}$.
