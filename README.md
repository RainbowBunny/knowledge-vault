# Knowledge Vault

Personal knowledge base maintained in [Obsidian](https://obsidian.md/).

## Structure

- `academic/` — academic notes and study material
- `competition/` — competitive programming / CTF notes
- `scripts/` — Obsidian Templater / DataviewJS scripts
- `templates/` — note templates
- `Fleeting MOC.md` — fleeting-notes map of content
- `Daily Note Workflow for Obsidian.md` — workflow doc

## Excluded from version control

The `daily/` folder is intentionally not tracked — it contains personal daily journal entries. See `.gitignore` for the full exclusion list.

## Workflow

1. Capture in `daily/` (private, local-only).
2. Promote durable ideas into the topical folders above.
3. Commit and push topical changes regularly.
