## 2017-650 Efficient Public Trace and Revoke

> [!scheme] Trace-and-Revoke from Inner-Product Functional Encryption
> - $\mathsf{Setup}(1^\lambda, 1^t, 1^r)$
> 	1. Let $(\mathrm{pk}, \mathrm{msk}) \leftarrow \mathcal{FE}.\mathsf{Setup}(1^\lambda, 1^\ell)$ where $\ell = t + r + 1$.
> 	2. Outputs the public key $\mathrm{pk}$ and master secret key $\mathrm{msk}$.
> - $\mathsf{KeyGen}(\mathrm{msk}, \mathrm{id})$
> 	1. Samples $\mathbf{x}_\mathrm{id} \leftarrow \mathbb{Z}_p^\ell$.
> 	2. Appends $p_{\mathrm{id}} = (\mathrm{id}, \mathbf{x}_\mathrm{id})$ to the public directory $\mathrm{pd}$.
> 	3. Let $\mathrm{sk}_\mathrm{id} \leftarrow \mathcal{FE}.\mathsf{KeyGen}(\mathrm{msk}, \mathbf{x}_\mathrm{id})$.
> 	4. Outputs $\mathrm{sk}_\mathrm{id}$.
> - $\mathsf{Enc}(\mathrm{pd}, \mathrm{pk}, \mathcal{R}, m)$:
> 	1. Computes $\mathbf{v}_\mathcal{R} \in \mathbb{Z}_p^\ell \backslash \{0\}$ such that $\langle \mathbf{x}_\mathrm{id}, \mathbf{v}_\mathcal{R} \rangle = 0 \; \forall \mathrm{id} \in \mathcal{R}$.
> 	2. Computes $\mathbf{y}_\mathcal{R} = m \cdot \mathbf{v}_\mathcal{R}$.
> 	3. Outputs $C = (C_1, C_2) = (\mathcal{FE}.\mathsf{Enc}(\mathrm{pk}, \mathbf{y}_\mathcal{R}), \mathcal{R})$.
> - $\mathsf{Dec}(\mathrm{pd}, \mathrm{sk}_\mathrm{id}, C)$:
> 	1. Parses $C_2 = \mathcal{R}$.
> 	2. If $\mathrm{id} \in \mathcal{R}$ then aborts.
> 	3. Computes $\mathbf{v}_\mathcal{R} \in \mathbb{Z}_p^\ell \backslash \{0\}$ such that $\langle \mathbf{x}_\mathrm{id}, \mathbf{v}_\mathcal{R} \rangle = 0 \; \forall \mathrm{id} \in \mathcal{R}$.
> 	4. Outputs $m = \mathcal{FE}.\mathsf{Dec}(\mathrm{sk}_\mathrm{id}, C_1) \backslash \langle \mathbf{x}_\mathrm{id}, \mathbf{v}_\mathcal{R} \rangle$.
> - $\mathsf{Trace}(\mathrm{pd}, \mathcal{R}, \mathcal{S}, \mathcal{O}^\mathcal{D})$:
> 	1. Finds $m, m' \in \mathcal{M}$ such that the following quantity is non-negligible: 
> 	$$\left|\Pr_{C \leftarrow \mathsf{Enc}(\mathrm{pd}, \mathrm{pk}, \mathcal{R}, m)}[\mathcal{O}^\mathcal{D}(C, m) = 1] - \Pr_{C' \leftarrow \mathsf{Enc}(\mathrm{pd}, \mathrm{pk}, \mathcal{R}, m')}[\mathcal{O}^\mathcal{D}(C', m) = 1] \right|$$
> 	2. Sets $\mathcal{S}_1 = \{\mathrm{id}_1, \mathrm{id}_2, \dots\} = \mathcal{S} \backslash \mathcal{R}$.
> 	3. Computes $\mathbf{v}_\mathcal{R} \in \mathbb{Z}_p^\ell \backslash \{0\}$

> [!example] Reduction B (proof of Theorem 16)
> | | FE challenger $\mathcal C_{\mathsf{FE}}$ | | reduction $\mathcal B$ | | adversary $\mathcal A$ |

> | | $\mathrm{sk}_{x_\mathrm{id}} \leftarrow \mathsf{FE.KeyGen}(\mathrm{msk}, x_\mathrm{id})$ | $\xrightarrow{\ \mathrm{sk}_{x_\mathrm{id}}\ }$ | $T \leftarrow T \cup \{\mathrm{id}\}$ | $\xrightarrow{\ \mathrm{sk}_\mathrm{id}\ }$ | |

> | | $b \leftarrow U(\{0,1\})$; $\mathrm{ct}^* \leftarrow \mathsf{FE.Enc}(\mathrm{pk}, y_b)$ | $\xrightarrow{\ \mathrm{ct}^*\ }$ | | | |
> | 9 | | | $\beta \leftarrow \mathcal O_D\big((\mathrm{ct}^*, R),\, m\big)$ (one query to $D$) | | |
> | 10 | | $\xleftarrow{\ b'\ }$ | $b' = \beta$ if $\hat p_i > \hat p_{i-1}$, else $b' = 1 - \beta$ | | |

> [!check] Validity of the challenge (step 8)
> | key queried by $\mathcal B$ | $\langle x_\mathrm{id}, y_0 \rangle$ | $\langle x_\mathrm{id}, y_1 \rangle$ | equal? |
> | --- | --- | --- | --- |
> | $\mathrm{id} \in R$ | $0$ | $0$ | ✓ |
> | traitor in $S_{i-1}$ (hence in $S_i$, since $\mathrm{id}_{i-1} \notin T$) | $m \langle x_\mathrm{id}, v_R \rangle$ | $m \langle x_\mathrm{id}, v_R \rangle$ | ✓ |
> | traitor in $S_1 \setminus S_{i-1}$ | $m' \langle x_\mathrm{id}, v_R \rangle$ | $m' \langle x_\mathrm{id}, v_R \rangle$ | ✓ |
> | $\mathrm{id}_{i-1}$ (**never queried**) | $m \langle x_\mathrm{id}, v_R \rangle$ | $m' \langle x_\mathrm{id}, v_R \rangle$ | ✗ |
>
> Uses $T \subseteq S$: a traitor outside $S$ has unconstrained $\langle x_\mathrm{id}, v_{S_i} \rangle$ and would make the challenge invalid.

> [!success] Advantage of $\mathcal B$
> Let $E$ be the event that $\mathsf{Trace}$ accuses an innocent $\mathrm{id}_{i-1} \notin T$, and $\gamma = \lvert p_i - p_{i-1} \rvert$. Since $\mathrm{ct}^*$ is distributed exactly as probe $i-1$ (if $b = 0$) or probe $i$ (if $b = 1$) and $D$ is stateless:
> $$\Pr[\beta = 1 \mid b = 1] - \Pr[\beta = 1 \mid b = 0] = p_i - p_{i-1}$$
> $$\mathrm{Adv}_{\mathcal B} = \Pr[E] \cdot \tfrac{\gamma}{2} - \mathrm{negl}(\lambda)$$
> - $\Pr[E] \geq 1/\lambda^c - \mathrm{negl}(\lambda)$: $\mathcal A$ wins, and by Lemma 17, $\mathsf{Trace}$ outputs $\bot$ only with negligible probability.
> - $\gamma$ is non-negligible: $\mathsf{Trace}$ only accuses when $\lvert \hat p_i - \hat p_{i-1} \rvert$ is non-negligible, and Hoeffding makes $\hat p_j \approx p_j$.
>
> So $\mathcal B$ breaks $(t+r)$-IND-CPA security of $\mathsf{FE}$, which is a contradiction. $\blacksquare$
