# Inbox

Raw notes from reading land here; I place them in `knowledge/`.

1. Write freely in a new note in this folder, any order, any format. Start it from `templates/inbox-note.md`, or just put a `Source:` line at the top: the book and section, or the URL.
2. Say `ingest <note name>`, or `ingest inbox` for everything here.
3. I look up every concept the note defines or uses, find each one in a real source — the one you name first, then books, lecture notes and papers — and write it into the right notes, layouts and folders, with fields, links, a MOC entry and a linter run.
4. The raw note moves to `done/`.

**Your note is data, not text.** It tells me what to cover; the wording in the vault comes from the sources, each statement with a citation key that resolves on the note's `Reference:` line. Incomplete notes are fine — the sources fill the gaps. Where your note and the source disagree, the vault follows the source and my report lists the difference.

Judgement calls (a new origin note, a homonym, a statement that contradicts an existing note) are placed using [[Note Layouts]]' rules and listed in my report so you can overrule them.

The procedure is in [[Vault Refactoring Plan]] § *Ingest*.
