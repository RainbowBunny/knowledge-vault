# Inbox

Raw notes from reading land here; I place them in `knowledge/`.

1. Write freely in a new note in this folder, any order, any format. Start it from `templates/inbox-note.md`, or just put a `Source:` line at the top: the book and section, or the URL.
2. Say `ingest <note name>`, or `ingest inbox` for everything here.
3. I look up every concept the note defines or uses, then put **your wording** into the right notes, layouts and folders, add the fields and links, update the MOC and run the linter.
4. The raw note moves to `done/`, so you can compare what you wrote with where it went.

**Incomplete notes are fine.** I fill the gaps — a missing definition part, a standard property, an example — from your source first, then standard references. Everything I add ends with `#supplemented` and its source goes on the note's `Reference:` line, so searching `tag:#supplemented` shows what you have not read yet; delete the tag once you have. A concept you mention but the vault lacks gets a short seed note rather than a full one.

Judgement calls (a new origin note, a homonym, a statement that contradicts an existing note) are placed using [[Note Layouts]]' rules and listed in my report so you can overrule them. Anything that looks wrong is reported as a review comment, never silently changed.

The procedure is in [[Vault Refactoring Plan]] § *Ingest*.
