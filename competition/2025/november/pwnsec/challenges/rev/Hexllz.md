First, we use `file` command to check the file type:

```
ELF 32-bit LSB executable, ARM, EABI5 version 1 (SYSV), statically linked, for GNU/Linux 3.2.0, stripped
```

We can see that this part is some kind of xor encryption in this section. As we know that after the decrypting process, we can see its ARM code, we can open with Ghidra with the same architect to get a flag checker.
