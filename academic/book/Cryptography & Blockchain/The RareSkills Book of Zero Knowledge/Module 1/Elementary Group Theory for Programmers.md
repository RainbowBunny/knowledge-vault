| Concept          | Meaning                                                                                                                                                           |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Finite groups    | group has a finite number of elements in it                                                                                                                       |
| Order of a group | number of elements in a group                                                                                                                                     |
| Cyclic group     | group that has an element such that every element in the group can be “generated” by applying the binary operator repeatedly to that element, or to it’s inverse. |
| Abelian group    | group with its binary operator is commutative                                                                                                                     |
- If a group is cyclic, then it is Abelian.
- The identity element of a group is unique.
