| Concept   | Definition                                            |
| --------- | ----------------------------------------------------- |
| Magma     | a set with a closed binary operator                   |
| Semigroup | a Magma where the binary operator must be associative |
| Monoid    | a Semigroup with an identity element                  |
| Group     | a Monoid in which each element has an inverse         |
