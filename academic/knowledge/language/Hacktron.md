
## Sessions

Prefix: `hacktron sessions`

| Command              | Explaination                                                                    |
| -------------------- | ------------------------------------------------------------------------------- |
| `list`               | List saved sessions, including the pack name, run ID, and last updated time.    |
| `restore <run-id>`   | Restore a session by the run ID.                                                |
| `delete <run-id>`    | Delete a specific sessions.                                                     |
| `clean --days <day>` | Clean up sessions by deleting all sessions older than a certain number of days. |
