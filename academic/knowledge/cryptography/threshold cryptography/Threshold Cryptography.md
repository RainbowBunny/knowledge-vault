
## Secret Sharing Scheme

> [!algorithm] Secret Sharing Scheme
> A **secret sharing scheme over** $Z$ is a pair of efficient algorithm $(G, C)$:
> - $G$ is a probabilistic **sharing algorithm** that is invoked as $(\alpha_1, \dots, \alpha_N) \xleftarrow{R} G(N, t, \alpha)$, where $0 < t \leq N$ and $\alpha \in Z$, to generate a $t$-out-of-$N$ sharing of $\alpha$.
> - $C$ is a deterministic **combining algorithm** that is invoked as $\alpha \leftarrow C(J, \{\alpha_j\}_{j \in J})$, where $J$ is a subset of $\{1, \dots, N\}$ of size $t$, to recover $\alpha$.
> **Correctness**: We require that for every $\alpha \in Z$, for every possible output $(\alpha_1, \dots, \alpha_N)$ of $G(N, t, \alpha)$, and every $t$-size subset $J$ of $\{1, \dots, N\}$, we have $$C(J, \{\alpha_j\}_{j \in J}) = \alpha.$$

> [!definition] Secure Secret Sharing Scheme
> A secret sharing scheme $(G, C)$ over $Z$ is **secure** if for all allowable parameters $0 < t \leq N$, for every $\alpha, \alpha' \in Z$, and every subset $J$ of $\{1, \dots, N\}$ of size $t - 1$, the distribution $G(N, t, \alpha)[J]$ is identical to the distribution $G(N, t, \alpha')[J]$.

### Shamir Secret Sharing

> [!algorithm] Shamir Secret Sharing
> ### Algorithm
> - $G_{sh}(N, t, \alpha)$: 
> 	1. Chooses random $k_1, \dots, k_{t - 1} \xleftarrow{R} \mathbb Z_q$ and define the polynomial $$\omega(x) = k_{t - 1} x^{t - 1} + k_{t - 2} x^{t - 2} + \dots + k_1 x + \alpha \in \mathbb Z_q[x].$$ 
> 	2. Notice that $\omega$ has degree at most $t - 1$ and that $\omega(0) = \alpha$. For $i = 1, \dots, N$ compute $\alpha_i \leftarrow \omega(i) \in \mathbb Z_q$. 
> 	3. Output the $N$ shares $\alpha_1, \dots, \alpha_N$.
> - $C_{sh}(J, \{\alpha_j\}_{j \in J})$: Since every polynomial of degree at most $t - 1$ is determined by its value at $t$ points, the $t$ shares $\alpha_j$ for $j \in J$ completely determine the polynomial $\omega$. Algorithm $C_{sh}$ interpolates the polynomial $\omega$ and outputs the constant term $\alpha = \omega(0)$.

> [!theorem] Security of Shamir Secret Sharing
> Shamir's secret sharing scheme $(G_{sh}, C_{sh})$ is secure. In particular, if $0 < t \leq N < q$, then for every $\alpha \in \mathbb Z_q$, any collection of $t - 1$ shares $\{\alpha_\ell\}_{\ell \in \mathcal L}$ is a mutually independent family of random variables, with each share uniformly distributed over $\mathbb Z_q$.

## Threshold Signature

> [!algorithm] Threshold Signature
> A **threshold signature scheme** $(G, S, V, C)$ is a tuple of four efficient algorithms:
> - $G$ is a probabilistic **key generation algorithm** that is invoked as $$(pk, pkc, sk_1, \dots, sk_N) \xleftarrow{R} G(N, t)$$ to generate a $t$-out-of-$N$ shared key. It outputs a **public key** $pk$, a **combiner public key** $pkc$, and $N$ **signing key shares**, $sk_1, \dots, sk_N$.
> - $S$ is a (possibly) probabilistic **signing algorithm** that is invoked as $\sigma_i' \xleftarrow{R} S(sk_i, m)$, where $sk_i$ is one of the key shares generated by $G, m$ is a message, and $\sigma_i'$ is a signature share for $m$ using $sk_i$.
> - $V$ is a deterministic **verification algorithm** as in a signature scheme, invoked as $V(pk, m, \sigma)$ and outputs either $\text{accept}$ or $\text{reject}$.
> - $C$ is a deterministic **combiner algorithm** that is invoked as $\sigma \leftarrow C(pkc, m, J, \{\sigma_j'\}_{j \in J})$, where $pkc$ is the combiner public key, $m$ is a message, $J$ is a subset of $\{1, \dots, N\}$ of size $t$, and each $\sigma_j'$ is a signature share for $m$. The algorithm either outputs a signature $\sigma$, or outputs a special message $\text{blame}(J^*)$, where $J^*$ is a nonempty subset of $J$. 
> Intuitively, the message $\text{blame}(J^*)$ indicates that the provided signature shares $\sigma_j'$ for $j \in J^*$, are invalid.
> **Correctness**: as usual, the verification algorithm should accept a properly constructed signature; specifically, for all possible outputs $(pk, pkc, sk_1, \dots, sk_N)$ of $G(N, t)$, all messages $m$, and all $t$-size subsets $J$ of $\{1, \dots, N\}$, we have $$P[V(pk, m, C(pkc, m, J, \{S(sk_j, m)\}_{j \in J})) = \text{accept}] = 1$$

### Generic Threshold Signature Scheme

> [!algorithm] Generic Threshold Signature Scheme
> Every secure signature scheme $(G, S, V)$ can be trivially transformed into a threshold signature scheme $(G', S', V', C')$ as follows:
> - During setup, the key generator creates $N$ key pairs $(pk_i, sk_i) \xleftarrow{R} G()$, for $i = 1, \dots, N$, and gives key $sk_i$ to signing server $i$. The public verification key is $pk = (pk_1, \dots, pk_N)$, and the combiner public key is the same, $pkc = pk$. More precisely, we define threshold key generation $G'(N, t)$ as an algorithm that outputs $(pk, pk, sk_1, \dots, sk_N)$.
> - To sign a message $m$, signing server $i$, for $i \in \{1, \dots, N\}$, outputs the signature share $\sigma_i' \xleftarrow{R} S(sk_i, m)$.
> - The combiner collects $t$ signature shares from the signing servers, and outputs all $t$ of them as the full signature. In more detail, algorithm $C'(pkc, m, J, \{\sigma_j'\}_{j \in J})$, where $pkc = (pk_1, \dots, pk_N)$ and $|J| = t$, first checks that each $\sigma_j'$ is a valid signature on $m$ under $pk_j$. If not, it outputs $\text{reject}(J^*)$, where $J^*$ is the set of indices $j$ for which $\sigma_j'$ is invalid. Otherwise, it outputs the signature $\sigma = (J, \{\sigma_j'\}_{j \in J})$.
> - Finally, algorithm $V'(pk, m, \sigma)$, where $pk = (pk_1, \dots, pk_N)$ and $\sigma = (J, \{\sigma_j'\}_{j \in J})$, outputs $\text{accept}$ if $|J| = t$ and each $\sigma_j'$ is a valid signature on $m$ under $pk_j$.

### Threshold Signature Security

> [!algorithm] Threshold Signature Security
> For a given threshold signature scheme $\mathcal S = (G, S, V, C)$, defined over $(\mathcal M, \Sigma)$, and a given adversary $\mathcal A$, we define the following attack game.
> - **Setup**: the adversary sends poly-bounded allowable parameters $N$ and $t$, where $0 < t \leq N$, and a subset $\mathcal L \subseteq \{1, \dots, N\}$ of size $t - 1$ to the challenger. The challenger runs $$(pk, pkc, sk_1, \dots, sk_N) \xleftarrow{R} G(N, t),$$ and sends $pk, pkc$, and $\{sk_\ell\}_{\ell in \mathcal L}$ to the adversary.
> - **Signing queries**: For $j = 1, 2, \dots$, signing query $j$ from $\mathcal A$ is a message $m_j \in \mathcal M$. Given $m_j$, the challenger computes all $N$ signature shares $\sigma_{j, i}' \xleftarrow{R} S(sk_i, m_j)$ for $i = 1, \dots, N$. It sends $(\sigma_{j, 1}', \dots, \sigma_{j, N}')$ to the adversary.
> - **Forgery**: Eventually $\mathcal A$ outputs a candidate forgery pair $(m, \sigma) \in \mathcal M \times \Sigma$.
> 
> We say that the adversary wins the game if the following two conditions hold:
> - $V(pk, m, \sigma) = \text{accept}$, and
> - $m$ is new, namely, $m \notin \{m_1, m_2, \dots\}$.
> 
> We define $\mathcal A$'s advantage with respect to $\mathcal S$ denoted $\text{thSIGadv}[\mathcal A, \mathcal S]$, as the probability that $\mathcal A$ wins the game.

> [!definition] Secure Threshold Signatures
> We say that a threshold signature scheme $\mathcal S$ is **secure** if for all efficient adversaries $\mathcal A$, the quantity $\text{thSIGadv}[\mathcal A, \mathcal S]$ is negligible.

### Robust Threshold Signatures

> [!definition] Robust Scheme
> Suppose a combiner receives a collection $\{\sigma_j'\}_{j \in J}$ of $t$ signature shares on a given message $m$. The combiner will output either a signature $\sigma$, or a special message $\text{blame}(J^*)$, where $J^*$ is a nonempty subset of $J$.
> - If the output of the combiner is $\text{blame}(J^*)$, then we would like it to be the case that all of the signature shares $\sigma_j'$ for $j \in J^*$ are "bad", in the sense that they were incorrectly generated by misbehaving signing servers. A threshold signature scheme that guarantees that this always happens is said to provide **accurate blaming**.
> - Otherwise, the output of the combiner is a signature $\sigma$ on the given message $m$. A threshold signature scheme is said to be **consistent** if no efficient adversary can cause the combiner to output a signature that is invalid on $m$, with non-negligible probability. When the combiner outputs a valid signature we say that the given collection of shares $\{\sigma_j'\}_{j \in J}$ is **valid** for $m$.
> 
> A threshold signature scheme is **robust** if it satisfies both properties.

> [!definition] Accurate Blaming
> We say that a threshold signature scheme $\mathcal S = (G, S, V, C)$ provides **accurate blaming** if the following holds:
> - For all possible outputs $(pk, pkc, sk_1, \dots, sk_N)$ of $G(N, t)$, all messages $m$, all $t$-size subsets $J$ of $\{1, \dots, N\}$, and all collections of signature shares $\{\sigma_j'\}_{j \in J}$:
> $$C(pkc, m, J, \{\sigma_j'\}_{j \in J}) = \text{blame}(J^*) \Rightarrow P[S(sk_j, m) = \sigma_j'] = 0 \quad \forall j \in J^*.$$

> [!algorithm] Consistent Threshold Signatures
> For a given threshold signature scheme $\mathcal S = (G, S, V, C)$, defined over $(\mathcal M, \Sigma)$, and a given adversary $\mathcal A$, we define the following attack game.
> - The adversary sends to the challenger poly-bounded allowable parameters $N$ and $t$, where $0 < t \leq N$.
> - The challenger runs $(pk, pkc, sk_1, \dots, sk_N) \xleftarrow{R} G(N, t)$ and sends all this data to the adversary.
> - The adversary outputs a message $m$, a subset $J$ of $\{1, \dots, N\}$ of size $t$, and a collection $\{\sigma_j'\}_{j \in J}$ of signature shares.
> - We say the adversary wins the game if $C(pkc, m, J, \{\sigma_j'\}_{j \in J})$ outputs a signature $\sigma$ (rather than a "blame" message), but $V(pk, m, \sigma) = \text{reject}$.
> We define $\mathcal A$'s advantage with respect to $\mathcal S$, denoted $\text{conSIGadv}[\mathcal A, \mathcal S]$, as the probability that $\mathcal A$ wins the game.

> [!definition] Consistent Threshold Signatures
> We say that a threshold signature scheme $\mathcal S$ is **consistent** if for all efficient adversaries $\mathcal A$, the quantity $\text{conSIGadv}[\mathcal A, \mathcal S]$ is negligible.

> [!definition] Robustness
> We say that a threshold signature scheme is **robust** if it provides accurate blaming and is consistent.

### BLS Threshold Signing

> [!algorithm] BLS Threshold Signature Scheme
> ### Building Block
> - Group $\mathbb G$.
> - Hash function $H: \mathcal M \rightarrow \mathbb G$.
> - BLS signature scheme
> 
> ---
> ### Algorithm
> We describe the BLS threshold signature scheme $\mathcal S_{thBLS} = (G', S', V', C')$:
> - $(pk, pkc, sk_1, \dots, sk_N) \leftarrow G'(N, t)$:
> 	1. Choose a random $\alpha \xleftarrow{R} \mathbb Z_q$ and compute $pk \leftarrow g^{\alpha}$;
> 	2. Run $G_{sh}(N, t, \alpha)$ to obtain $N$ shares $\alpha_1, \dots, \alpha_N \in \mathbb Z_q$;
> 	3. For $i = 1, \dots, N$, compute $u_i \leftarrow g^{\alpha_i}$, and set $sk_i = \alpha_i$ and $pk_i = u_i$; 
> 	4. Set $pkc = (pk_1, \dots, pk_N)$;
> 	5. Output $(pk, pkc, sk_1, \dots, sk_N)$.
> - $\sigma_i' \leftarrow S'(sk_i, m)$, where $sk_i = \alpha_i$: output the signature share $\sigma_i' \leftarrow H(m)^{\alpha_i} \in \mathbb G$.
> - $\sigma \leftarrow C'(pkc, m, J, \{\sigma_j'\}_{j \in J})$, where $J$ is a subset of $\{1, \dots, N\}$ of size $t$, and $$pkc = (pk_1, \dots, pk_N) = (u_1, \dots, u_n):$$
> 	- Step 1: Verify that all $t$ signature shares are valid: let $J^*$ be the set of all $j \in J$ such that $$V_{BLS}(u_j, m, \sigma_j') = \text{reject};$$ if $J^*$ is nonempty, output $\text{blame}(J^*)$ and abort;
> 	- Step 2: Compute the signature: Interpolate in the exponent with the given set $J$ and $j^* = 0$ to compute the signature $\sigma = H(m)^{\alpha} = H(m)^{\omega(0)}$ from the $t$ group elements $\sigma_j' = H(m)^{\omega(j)}$ for $j \in J$; output $\sigma$ as the signature on $m$; more explicitly, the signature $\sigma$ is computed as $$\sigma \leftarrow \prod_{j \in J}(\sigma_j')^{\lambda_j} \in \mathbb G$$ where the exponents $\{\lambda_j\}_{j \in J}$ are the Lagrange interpolation coefficients.
> - $V'(pk, m, \sigma)$: Output $V_{BLS}(pk, m, \sigma)$.

> [!theorem]
> If $\mathcal S_{BLS}$ is a secure signature scheme, then $\mathcal S_{thBLS}$ is a secure threshold signature scheme.
