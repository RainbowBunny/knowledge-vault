
> [!definition] Hyperelliptic Curve
> A **hyperelliptic curve of genus** $g$ is the set of solutions to an equation of the form $$C: Y^2 = X^{2g + 1} + A_1 X^{2g} + \cdots + A_{2g} X + A_{2g + 1}$$ with the added requirement that the polynomial $F(X) = X^{2g + 1} + \cdots + A_{2g + 1}$ have distinct roots.
