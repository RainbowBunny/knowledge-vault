# Pwn CTF Challenges

Index of all pwn challenges across competitions, grouped by year. Pulled live from `competition/` via Dataview.

## 2016

```dataview
TABLE event, note, solved
FROM "competition/2016"
WHERE type = "challenge" 
  AND category = "pwn"
SORT event ASC
```
